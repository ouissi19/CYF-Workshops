Consider the code in this program below:

```js
function calculateSum(a, b) {
  return a + b;
}

function logSum(a, b) {
  console.log(a + b);
}

const result1 = calculateSum(10, 32);
const result2 = logSum(10, 32);
```

a) what will `result1` evaluate to? Explain your answer
The result of 'result1' is 42

b) What will `result2` evaluate to? Explain your answer

it will desplay 42 on the console, but it does not save the result in 'result2' since it does not use return

c) Try to summarise the main difference between `logSum` and `calculateSum`
Basically on the function calculateSum, it calculates a + b(which in this case is 10+32) and then return sends 42 back and it's saved in resul1.
The second function logSum, it calculates 10+32, console.log() displays 42 on the console but nothing is returned. So in this case 'result2' is undefined.
